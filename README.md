## 📚 Sobre o repositório

Este espaço reúne meus trabalhos e estudos da graduação em **Análise e Desenvolvimento de Sistemas (ADS)**. O objetivo é registrar a evolução do aprendizado, organizar entregas acadêmicas e documentar soluções desenvolvidas em diferentes disciplinas.

Aqui podem ser encontrados exercícios práticos, aplicações, testes de tecnologias e projetos que integram conceitos vistos em sala de aula.

## 🚀 Projetos em destaque

### 🧠 Synora Acadêmico

Aplicativo Android desenvolvido em **Flutter e Dart** para auxiliar na organização de atendimentos psicológicos, com **SQLite local** e funcionamento offline.

**Funcionalidades desenvolvidas:**
- Cadastro e gerenciamento de pacientes;
- Agenda de consultas e acompanhamento de status;
- Registro de atendimentos;
- Controle de pagamentos;
- Painel com visão dos agendamentos;
- Perfil do profissional.

📂 **[Acessar código e documentação do Synora](./Mobile/synora_academico)**

📱 **[Ver versões e APKs disponíveis](https://github.com/OeGiaretta/faculdade/releases)**

> O Synora Acadêmico é um protótipo educacional. Utilize dados fictícios nos testes.

## 🛠️ Tecnologias e conhecimentos

Ao longo das atividades acadêmicas, são explorados temas como:

- **Programação:** Python, Java, Go e Dart;
- **Desenvolvimento mobile:** Flutter;
- **Desenvolvimento web:** HTML, CSS e JavaScript;
- **Banco de dados:** SQL, PostgreSQL e SQLite;
- **Engenharia de software:** modelagem, orientação a objetos e organização de projetos;
- **Ferramentas:** Git, GitHub e ambientes de desenvolvimento.

> As tecnologias variam conforme a disciplina e o projeto. Esta lista representa áreas de estudo, não necessariamente dependências de todas as pastas.

## 💻 Como utilizar

Clone o repositório:

```bash
git clone https://github.com/OeGiaretta/faculdade.git
cd faculdade
```

Em seguida, entre na pasta do projeto desejado e consulte suas instruções específicas. Os requisitos e comandos de execução podem variar entre atividades.

## 🎯 Objetivo

Mais do que armazenar entregas, este repositório funciona como um **histórico de aprendizado**, permitindo revisitar conceitos, acompanhar a evolução técnica e compartilhar implementações acadêmicas.
